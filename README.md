## How to launch

Need **Node.js** + **npm**. Use **two terminals**. Start **backend** first (frontend talks to it on port **5001**).

**Backend**

```bash
cd StarterCode/backend
npm install
npm run dev
```

API: `http://localhost:5001` (change with env `PORT` if needed).

**Frontend**

```bash
cd StarterCode/frontend
npm install
npm start
```

App: `http://localhost:3000`.  
(`package.json` **`proxy`** sends `/api` to port **5001**)
